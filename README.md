## Justificación 

Fue elegido el modo "solo Anfitrión" para aislar la red externa. La VM se utilizará a modo de prueba de manera temporal hasta que pueda habilitar una PC mejor donde correr una VM en mejores condiciones, por lo tanto se consideró mejor opcion que Guest tenga acceso restringido a la Web. No se utilizó el modo "Bridged" puesto que este modo se conecta al Router como una maquina mas, por lo tanto se considera un riesgo innecesario ante amenazas externas.
