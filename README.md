## Justificación 

Fue elegido el modo "solo Anfitrión". La VM se utilizará a modo de prueba de manera temporal hasta que pueda habilitar una PC mejor donde correr una VM en mejores condiciones, por lo tanto se consideró mejor opcion que la VM y el Host tengan comunicación internet sin necesidad de navegar la web con la VM. No se utilizó el modo "Bridged" para evitar que el Guest se conecte directamente al router de mi casa.
